One line of software error copy for the [Say What Actually Broke](https://make.fun/bounty/u-po-pu-say-what-actually-broke-a2c153b5) bounty on make.fun: it tells the user the brutal truth about what went wrong and makes them laugh on the way.

> The update failed at 99% because your laptop died at 98%. Plug it in — the update is patient, the battery is not.

`main.py` writes that line to `/output/entry.txt` (113 characters, single line, UTF-8). Stdlib only, deterministic.
